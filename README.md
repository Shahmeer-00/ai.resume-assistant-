# ATS Resume Scanner & Optimizer

An AI-powered web application built with Streamlit and Google Gemini Flash that evaluates resumes against job descriptions, calculates ATS (Applicant Tracking System) scores, and provides structured feedback for improvement.

## Features
- Support for **PDF** and **DOCX** files.
- Real-time ATS match scoring and breakdown.
- Key strengths and targeted improvements feedback.
- Keyword missing identification based on uploaded job descriptions.
